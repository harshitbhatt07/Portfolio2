# Himanshu Portfolio

React + Vite personal portfolio.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy on Vercel
- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`

## Deploy on GitHub Pages
```bash
npm install
npm run deploy
```

This project uses `base: "./"` so assets work on GitHub Pages repo paths and Vercel/Netlify root paths.
